**On this page**, you will find a comprehensive and detailed worklog of my 10-week internship as an **ML Engineer** at the First Cloud AI Journey (AWS), covering the period from **05/06/2026 to 15/08/2026**.

The worklog is structured chronologically, documenting the progression from foundational AWS environment setup to advanced MLOps, Deep Learning, and production deployment.

The detailed weekly breakdown is as follows:

**Week 1:** [Onboarding, IAM Security & S3 Data Lake Setup](1.1-week1/)
*(Getting familiar with the team, setting up IAM roles, AWS CLI configuration, and designing the project's S3 architecture.)*

**Week 2:** [SageMaker Studio Setup & Data Preprocessing](1.2-week2/)
*(Exploring SageMaker Studio, performing comprehensive EDA, data cleaning with Pandas, and uploading processed datasets back to S3.)*

**Week 3:** [Baseline Model Training & Evaluation](1.3-week3/)
*(Configuring SageMaker Estimators, training baseline models using XGBoost and Linear Learner, and evaluating performance against business KPIs.)*

**Week 4:** [Hyperparameter Optimization (HPO) with SageMaker](1.4-week4/)
*(Mastering HPO concepts, implementing Bayesian search strategies, and extracting optimal parameters to significantly improve the baseline model.)*

**Week 5:** [Deep Learning & Time-Series Forecasting with DeepAR](1.5-week5/)
*(Transitioning to Deep Learning, configuring GPU instances, and implementing a DeepAR model for advanced time-series forecasting.)*

**Week 6:** [Model Deployment & Real-Time Inference](1.6-week6/)
*(Deploying models to production SageMaker Endpoints, implementing Batch Transform jobs, and configuring Auto Scaling for high availability.)*

**Week 7:** [MLOps Pipelines & Model Registry](1.7-week7/)
*(Building automated SageMaker Pipelines, orchestrating workflows with Step Functions, and versioning models using the Model Registry.)*

**Week 8:** [Feature Store & Low-Code Data Wrangling](1.8-week8/)
*(Managing features centrally with SageMaker Feature Store and utilizing Data Wrangler for visual, low-code data transformation and cleaning.)*

**Week 9:** [System Integration & Cost Optimization](1.9-week9/)
*(Merging individual system components, implementing Spot Instances to reduce training costs, and performing end-to-end system integration tests.)*

**Week 10:** [Final Documentation, Demo & Presentation](1.10-week10/)
*(Finalizing the system, writing comprehensive technical documentation, preparing the final presentation deck, and concluding the internship program with a final project demo.)*
